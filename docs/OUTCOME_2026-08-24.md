## Verdict

The board is materially more coherent and historically balanced. It is fit to
publish as a **tiered whole-sport estimate**, not as an exact ordinal GOAT list.
The input graph and age coverage support every top-100 name, but uncertainty
and an unattributed cross-era scale gradient remain real limits.

## Model checks

- Age-aware minus driftless held-out log loss: **-0.00382** overall
  (95% event-bootstrap interval [-0.00693, -0.00091]) and **-0.00965** for bouts
  involving a fighter over 35 ([-0.01702, -0.00257]).
- Narrowest adjacent-year bridge since 2000: **340 shared fighters**, up from 14.
  **370** fighters span 2000-04 and 2016+, up from 10.
- Conditional debut-year gradient: **+5.20 rating points/year** (t=13.93). The
  graph is no longer narrow, but this residual remains unattributed between
  actual skill growth and rating-scale drift.
- The correctly gated 12-replicate exploratory bootstrap yields four tiers and
  a median top-50 rank width of **91**. Tier 1 contains Jones through Khabib;
  Jones itself spans ranks [1, 14]. Twelve replicates are enough to reject exact
  ordinal presentation, not enough for release-grade interval endpoints; use
  150+ when a multi-hour release build is budgeted.
