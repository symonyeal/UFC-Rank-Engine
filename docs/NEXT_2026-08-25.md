## 1. The scope model, as it now stands

Scopes are named in `ratings/scope.py`. Nothing merges unless named; an
unsatisfiable scope raises and names the builder that would fix it.

| scope | artifact | what it is |
|---|---|---|
| `ufc` | — | UFCStats, UFC 28 onward. Historical baseline scope |
| `pre_unified` | `pre_unified_fights.parquet` | UFC 1-27, recovered from `_excluded_bouts.csv` |
| `majors` | `majors_fights.parquet` | Sherdog whole-career, 63,813 bouts, 1980-2026 |
| `fightmatrix` | `fightmatrix_crossorg_fights.parquet` | bounded ranked-cohort crawl |
| `all` | — | every staged corpus |

Combine explicitly: `--scope majors,pre_unified`. Merge order is **source
authority** (`SCOPE_MERGE_ORDER`), never the order written, so a scope spec
cannot decide whose parse of a shared bout survives the dedupe guard.

**Board profile, 0.9 bar:**

|---|---:|---:|---:|---:|---:|---:|

## 2. Current remaining limits

These are live limits after the completion pass, not stale blockers.

* **Release-grade intervals need a longer bootstrap.** The checked run uses 12
  replicates to prove the board must be shown as tiers, not exact ranks. Use
  150+ replicates before treating interval endpoints as publication-grade.
* **Cross-era scale still has an unattributed gradient.** The whole-career
  graph is no longer narrow, but debut year still contributes about +5.20 rating
  points/year after controls. The report names it as unresolved rather than
  hiding it in the board.
* **`ratings/rules_era.py` labels only UFC pre-unified bouts.** PRIDE and other
  promotions had their own rule environments. A date-keyed cross-promotion
  rules term would become an organisation weight under another name, so the
  current label stays narrow by design.
* **Full-repo ruff is not a project invariant yet.** The test suite is the
  release gate. Broad ruff still reports legacy notebook/import-layout and
  untouched-loader style findings; changed production paths were kept clean.
