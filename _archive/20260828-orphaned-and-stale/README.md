# Archived 2026-08-28 — an orphaned module and one stale generated artifact

Moved out of the live tree during the rating-layer and ledger pass
(`docs/RATING_LAYER_AND_LEDGER_2026-08-28.md`). Nothing here was deleted, and
every original path is recorded below.

## `ratings/field_depth.py` and `tests/test_field_depth.py`

**Original paths:** `ratings/field_depth.py`, `tests/test_field_depth.py`.

Division-year field depth `D(d, a)`, the contender line `C(d, a)`, and the
per-appearance `field_pct` column. It was Phase 0 of the whole-sport plan and
was always reporting-only: nothing in it ever fed the rating layer.

**Why it is archived now.** It has no importer left in the live tree. Its only
driver, `build_field_depth.py`, was archived on 2026-08-25, and the note in
`_archive/20260825-superseded-research-drivers/README.md` that
"`ratings/field_depth.py` is still live and imported" was **already wrong when
it was written** — the only import was from the file being archived beside it.
That claim is corrected in place. The 2026-08-28 pass then removed the last dead
function inside it (`opponent_quality_by_period`), which made the situation
obvious: a module, a test that imports nothing but that module, and no caller.

**What replaced it.** The bar the published board actually uses lives in
`ratings/symon_score.py` — `year_reference` and `division_year_reference`, struck
inside each division-year at `contender:5` with a sport-wide `contender:60`
fallback, under the spread-relative hinge. `legacy_resume.title_quality_ledger`
strikes its own contender line for title pricing. Neither goes through this
module.

**If you need it back:** it is self-contained and imports only numpy/pandas.
`git mv` it and its test back, and restore `build_field_depth.py` from
`_archive/20260825-superseded-research-drivers/`.

## `generated-data/top100_bar_comparison-2026-08-24.parquet`

**Original path:** `data/model_tuning/top100-audit/top100_bar_comparison.parquet`.

The only file in that directory not regenerated by the 2026-08-28
`build_top100_audit.py` run. It was written on 2026-08-24, so it predates **both**
the 2026-08-27 career-coverage repair (67,920 -> 80,697 model bouts) and every
change in the 2026-08-28 pass: the scale-equivariant career functional, the
refit WHR constants, the method-of-victory winner score, and the pool-priced
title ledger.

**Do not cite any number in it as current.** It was archived rather than
deleted only so the earlier bar comparison remains recoverable; regenerate it
instead if the comparison is wanted again.

## `generated-data/career_mass_{uncertainty,tiers}-2026-08-24.*`

**Original paths:** `data/snapshots/2026-08-13/career_mass_uncertainty.parquet`,
`career_mass_uncertainty.json`, `career_mass_tiers.parquet`.

Rank intervals and tiers written on 2026-08-24. They were stale in four separate
ways at once — they predate the career-coverage repair, the refit WHR constants,
the method-of-victory winner score and the pool-priced title ledger — and they
were also **mixed-population**: men and women ranked against each other, which
is an ordering claim no bout in the corpus supports.

That combination is why they were moved rather than left in place. After the
2026-08-28 gender split, `career_mass_uncertainty.parquet` is by name the
**men's** artifact, so leaving a mixed 2026-08-24 file sitting at that path
would have handed any reader a stale mixed board under the men's name.

Regenerate with `python build_uncertainty.py <snapshot> --replicates N`, and
`--gender F` for the women's intervals.

`generated-data/` is gitignored (`_archive/**/generated-data/`), so these files
stay local and are not versioned.
